Element Guard
=============
Install: chrome://extensions -> enable Developer mode -> Load unpacked -> select this folder.

Use: click the extension icon -> "Pick an element to block" (or press Alt+Shift+E on the page).
Hover to highlight, click to select, then Block / Cancel in the confirm box.
Use Parent / Child to widen or narrow the selection, or edit the selector by hand.
Esc cancels. Rules are saved per site (or for all sites) and managed from the popup.
